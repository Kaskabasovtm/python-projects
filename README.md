# python-projects
Продажи и погода · Python (pandas)
Задача

Проанализировать ежедневные продажи за январь–август 2018 года и проверить, связаны ли они с погодой.

Данные
data.csv — 301 355 строк продаж: дата, склад, контрагент, товар, количество.
Погода.xlsx — архив погоды в Астане с rp5.ru (6–8 наблюдений в сутки).
Что сделано
Проверка типов и пропусков, приведение дат к формату datetime.
Группировка продаж по дням и график динамики с описанием тренда, недельной цикличности и аномалий.
Поиск выброса в исходных данных и топового товара по средам летом на складе №3.
Разбор «сырого» файла погоды: поиск строки заголовков, расчёт средней температуры за день, объединение с продажами по дате (240 дней, без пропусков).
Совмещённый график продаж и температуры, выводы.
Результаты
Продажи выросли с 3 500–4 000 шт. в день зимой до 4 500–6 000 шт. летом. Рост начался резким скачком в конце апреля.
Скачок совпадает с потеплением выше +10 °C, но день в день продажи за температурой не следуют. Сильные морозы в январе (до −35 °C) на продажах не видны.
Найдена разовая аномалия в середине апреля: продажи почти вдвое ниже соседних дней.
Инструменты
